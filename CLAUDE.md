# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Personal site for Ovilli (ovilli.de). One HTML page, one stylesheet, no JavaScript, no build tools, no package manager, no test suite. Hosted on GitHub Pages with Cloudflare in front. English.

It is **not** a portfolio and should not drift into one. No "hire me", no skills matrix, no CV link, no case studies, no selling. Just a name, a few things built, and a way to reach him.

Keep it one page. The site was deliberately cut down from a larger animated multi-page site; new pages and dependencies need to justify themselves.

## Dev

No build step. Open `index.html` in a browser.

## Files

- `index.html` — the entire site
- `css/style.css` — the entire stylesheet
- `assets/og.png` — social preview, 1200×630, generated by a Pillow script (kept outside the repo; regenerate if the look changes)
- `assets/olive-svgrepo-com.svg` — favicon and the mark at the top of the page

## Look

Modelled on <https://nhcham.org>, which the owner likes: dark, centered, monospace, muted greys, minimal markup, content as headings plus one-line links. Adapted rather than copied — where that site uses a `§` between sections, this one uses an olive drawn in CSS (`hr::after`), and the accent is olive rather than grey.

- Dark only, on purpose. No `prefers-color-scheme` light variant.
- No webfonts. System `--mono` stack only — a `.de` site pulling Google Fonts is a GDPR problem, which is why the reference site's PT Mono was not carried over.
- Everything is centered by `body { text-align: center }`. There is no layout system and there does not need to be one.
- No third-party scripts, no analytics, no ads. The fine print says so, so adding any means updating that text.
- Descriptions must match what each repo actually does. An earlier version of this site claimed macOS support and a browser version for the Ravenswatch Mod Manager, neither of which existed.

## Legal

Purely private page — no ads, nothing on offer — so it carries a short fine-print note instead of a full German Impressum with a postal address. If anything commercial is ever added, a proper Impressum becomes mandatory.

## CI

`.github/workflows/purge-cache.yml` auto-purges Cloudflare cache on every push to `master`.
